   - `nodes/cypher.py`: `generate_cypher_node(state)` returns `{"cypher_query": "MATCH (n) RETURN n"}`
   - `nodes/validate.py`: `validate_node(state, driver)` returns `{"db_results": [{"stub": True}]}` (takes driver param for closure injection)
   - `nodes/analyze.py`: `analyze_node(state)` returns `{"analysis_result": "stub analysis"}`
   - `nodes/format.py`: `format_node(state)` returns `{"final_output": {"frontline": [], "reserve": [], "synergy_explanation": "stub"}}`

   Each stub must import `WorkflowState` from `..state`. No LLM imports yet in stubs (those come in plans 02-02 through 02-04).

6. Create `src/workflow/graph.py` with:
   - `route_after_validate(state: WorkflowState) -> Literal["generate_cypher", "analyze", "format"]`:
     ```python
     def route_after_validate(state: WorkflowState) -> Literal["generate_cypher", "analyze", "format"]:
         if state.get("db_results"):
             return "analyze"
         if state.get("retry_count", 0) >= 3:
             return "format"
         return "generate_cypher"
     ```
     This works because VALIDATE only writes `db_results` on success (non-empty list) and only increments `retry_count` on failure. Since `db_results` has no reducer (overwrites), and the flow never returns to VALIDATE after routing to ANALYZE, `db_results` is either `[]` (never succeeded) or non-empty (just succeeded).

   - `build_graph(driver=None)` function that:
     - Creates `StateGraph(WorkflowState)`
     - Adds all 5 nodes. For validate, use closure: `builder.add_node("validate", lambda s: validate_node(s, driver))`
     - Adds edges: START->plan, plan->generate_cypher, generate_cypher->validate, analyze->format, format->END
     - Adds conditional edge: `add_conditional_edges("validate", route_after_validate, ["generate_cypher", "analyze", "format"])`
     - Returns `builder.compile()`
   - Module-level `compiled_graph = build_graph()` (driver=None for stub/test use)
   - Export both `build_graph` and `compiled_graph`
