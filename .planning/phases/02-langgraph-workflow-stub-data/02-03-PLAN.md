<objective>
Implement the VALIDATE node as a TWO-STEP HYBRID gate (deterministic driver execution + Haiku 4.6 semantic evaluation) and update graph routing tests to work with the real validate implementation.

Purpose: VALIDATE is the critical safety gate — it prevents both syntactically broken AND semantically wrong Cypher from reaching ANALYZE. Step 1 catches driver-level failures (syntax errors, missing labels, empty results). Step 2 catches domain-level mistakes (e.g., query returned slash-zone characters when user asked for blunt-zone). The retry loop is the most complex control flow in the pipeline and must be tested at both unit and graph levels.

Output: Working VALIDATE node with hybrid gate, updated graph routing tests confirming retry behavior for all three failure modes.
</objective>
