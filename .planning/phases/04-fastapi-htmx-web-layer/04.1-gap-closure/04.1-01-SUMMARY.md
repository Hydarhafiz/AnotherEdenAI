## Changes Per File

### src/web/templates/partials/progress.html (commit c6ca613)

- **Line 12 (comment):** `htmx:sseMessage` → `htmx:sseBeforeMessage (pre-swap, cancellable)`
- **Line 41 (addEventListener):** `"htmx:sseMessage"` → `"htmx:sseBeforeMessage"`

`htmx:sseBeforeMessage` fires before HTMX swaps SSE payload into the DOM; `evt.preventDefault()` cancels the swap so raw JSON never appears in the div. The post-swap `htmx:sseMessage` event makes `preventDefault()` a no-op.
