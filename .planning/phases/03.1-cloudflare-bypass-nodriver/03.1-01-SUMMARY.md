## Changes Made

### pyproject.toml
- Added `"nodriver>=0.48.1"` to `[project]` dependencies list
- httpx retained (used elsewhere in project)

### pytest.ini
- Added `scraper: marks tests requiring a live browser and network connection` marker

### src/etl/models.py
- Added `WEAPON_OVERRIDES: dict[str, str]` constant with Anabel ES=Spear, Mazrika=Axe entries
- Modified `parse_character()` to call `char.model_copy(update={"weapon": WEAPON_OVERRIDES[char.name]})` after `model_validate()` when the character name is in the overrides dict

### src/etl/scraper.py (full rewrite)
- Removed: `import httpx`, `import asyncio`, `SEMAPHORE`, `LIMITS`, `HEADERS`, `TIMEOUT`
- Added: `import nodriver as uc`, `CHROMIUM_PATH` constant
- New `fetch_page(browser, url)`: uses `browser.get(url)`, `tab.sleep(2)`, `tab.get_content()` — detects "Just a Moment" Cloudflare page and raises RuntimeError
- New `scrape_all()`: opens single nodriver browser, iterates 7 URLs sequentially, closes in `finally: browser.stop()` (T-3.1-03 mitigation)
- Parse functions (parse_characters, parse_grastas, parse_vc_grastas, parse_ores) preserved byte-for-byte

### tests/integration/test_etl_scraper.py (new file)
- `test_fetch_page_returns_beautifulsoup`: verifies fetch_page returns BeautifulSoup with >= 100 character rows
- `test_scrape_all_returns_expected_structure`: verifies scrape_all returns all 3 keys with expected counts
- Both tests decorated with `@pytest.mark.integration` and `@pytest.mark.scraper`
