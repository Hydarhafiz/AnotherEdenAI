# External Integrations

**Analysis Date:** 2026-03-14

## APIs & External Services

**Web Scraping:**
- Another Eden Wiki (`anothereden.wiki`)
  - What it's used for: Live game data fetching for characters, grastas, and ores
  - SDK/Client: BeautifulSoup 4 (bs4) for HTML parsing + requests for HTTP
  - Auth: None (public wiki, no authentication required)
  - Endpoints scraped from `master_scraper.py` lines 7-15:
    - `https://anothereden.wiki/w/Characters`
    - `https://anothereden.wiki/w/Grasta_Attack`
    - `https://anothereden.wiki/w/Grasta_Life`
    - `https://anothereden.wiki/w/Grasta_Support`
    - `https://anothereden.wiki/w/Grasta_Special`
    - `https://anothereden.wiki/w/Grasta_VC`
    - `https://anothereden.wiki/w/Grasta_Ores`

## Data Storage

**Databases:**
- None currently implemented
- README.md (line 16) indicates future additions: Neo4j or ChromaDB planned but not yet integrated

**File Storage:**
- Local filesystem only
- Output location: Project root directory
- Generated files:
  - `ae_characters.csv` - Character metadata and personality traits
  - `ae_grasta_master.csv` - Grasta equipment by category (Attack, Life, Support, Special, VC)
  - `ae_ores.csv` - Enhancement ore data
  - `ae_traits.csv` - Master trait vocabulary (generated by `separate_trait_grasta.py`)

**Caching:**
- None - Data is fetched fresh each run from wiki

## Authentication & Identity

**Auth Provider:**

## Future Integrations

**Planned (from README.md):**
- Neo4j - Knowledge graph database for storing character/trait/grasta relationships

## Data Flow

1. `master_scraper.py` - Fetches raw HTML from wiki
2. BeautifulSoup parses HTML using CSS selectors
3. Data extracted to Pandas DataFrames
4. CSV files written to disk
5. `optimize_character.py` - Reads CSVs and performs optimization logic
6. `separate_trait_grasta.py` - Generates trait master list from character and grasta data
